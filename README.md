# 高校情報Ⅰ：XOR暗号化・復号化ラボ (XOR Cipher & Bitwise Operations Laboratory)

## 高等学校の新学習指導要領「情報Ⅰ」（「(3) 情報通信ネットワークとデータの活用」および「(1) 情報社会の問題解決」）に対応した、排他的論理和（XOR）による暗号化・復号化の原理を体感的に学ぶインタラクティブWeb教材です。

### 🎯 学習目標

排他的論理和（XOR）の性質理解

$0 \oplus 0 = 0$ / $1 \oplus 0 = 1$ / $0 \oplus 1 = 1$ / $1 \oplus 1 = 0$ （値が異なるときのみ1）の動作を理解する。

可逆性（二重XORの法則）: $(A \oplus B) \oplus B = A$ となるため、同じ鍵で2回XOR演算を行うと元の値に戻ることを理解する。

共通鍵暗号（対称鍵暗号）の基礎

送信者と受信者が同じ「暗号鍵」を共有することで暗号化・復号化が行われる仕組みを学ぶ。

デジタルデータの暗号化原理

テキスト（UTF-8/2進数）だけでなく、画像（RGBピクセル値）など、あらゆるデジタルデータ（ビット列）が同様の計算で暗号化できることを視覚的に実感する。

### ✨ 主な機能

1. テキストXOR暗号・復号可視化

任意のメッセージ（平文）と暗号鍵（Key）を入力し、バイト単位（8ビット）でのXOR演算プロセスを追跡できます。

1回目のXORで生成された暗号文（16進数/ビット列）に対し、再度同じ鍵でXORを計算すると一瞬で元の文字に復元されるプロセスを色分けカードで可視化します。

サンプル文字列（"INFO", "情報Ⅰ"など）をワンクリックで挿入可能。

2. 画像ピクセル暗号ラボ

デジタル画像（160×160ピクセルのRGB値）に対して、擬似乱数で生成した鍵画像パターンとのXOR演算を実施します。

暗号化（1回目）: 元画像が完全な砂嵐ノイズ状態に変化。

復号化（2回目）: 砂嵐画像にもう一度同じ鍵でXORをかけると、1ピクセルの誤差もなく完璧に元の美しい画像に復元。

3. XOR回路・真理値表シミュレータ

1ビットの入力A（平文）と入力B（鍵）をボタンクリックで切り替え、リアルタイムに出力Yの変化を確認できる回路シミュレータです。

真理値表の対応する行がハイライトされ、自己消去律 ($A \oplus A = 0$) や単位元 ($A \oplus 0 = A$) などの数学的性質が直感的に学べます。

4. 教科書解説＆理解度チェッククイズ

情報セキュリティにおけるワンタイムパッド（理論上解読不能な暗号）や共通鍵暗号のポイントを整理。

授業のまとめや確認テストに活用できる多肢選択式の理解度クイズを搭載。

### 🛠️ 技術スタック・利用ライブラリ

HTML5 / CSS3 / JavaScript (ES6+): 外部サーバーへの依存やバックエンド処理なしで、ブラウザのみで完全動作します（完全クライアントサイド実行）。

Tailwind CSS: モダンで視認性の高いダークモードデザインUI。

HTML5 Canvas API: 画像データのピクセル（ImageData）取得・直接ビジーピクセルXOR演算。

Lucide Icons: アイコン表示。

Canvas Confetti: 復号成功時・クイズ正解時の演出アニメーション。

### 🚀 実行方法

index.html ファイルをローカルPCにダウンロードします。

ダブルクリックするか、任意のWebブラウザ（Google Chrome, Microsoft Edge, Safari等）にドラッグ＆ドロップして開きます。

ネットワーク接続がない環境（オフライン環境）でもローカル動作が可能です（CDNライブラリのキャッシュ済またはスタンドアロン動作時）。
