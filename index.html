暗号化の基本原理

文字を二進数（8ビット/UTF-8）に変換し、暗号鍵のビットとXOR（排他的論理和）を計算します。 暗号化されたデータにもう一度同じ鍵でXORを計算すると、完全に元の文字に復元（復号）できます！

画像データ（ピクセル値）のXOR暗号化

デジタル画像はRGB（赤・緑・青）の数値の集まりです。各ピクセルのRGB値に暗号鍵（パターンデータ）でXOR演算を行うと、 画像の意味が失われた「完全な砂嵐（暗号画像）」になります。 そこにもう一度全く同じ鍵でXOR演算を行うと、元の美しい画像が一瞬で復元します！

XOR（排他的論理和）の真理値表

入力 A 入力 B 出力 (A ⊕ B) 覚え方・特徴
0 0 0 同じ値なら 0
0 1 1 異なれば 1 （ビット反転）
1 0 1 異なれば 1
1 1 0 同じ値なら 0

💡 教科書で押さえる重要な3つの数学的性質

  • 自己消去律 (Self-inverse): $A \oplus A = 0$ （同じ値同士のXORは常に0）
  • 単位元 (Identity): $A \oplus 0 = A$ （0とのXORは値を変えない）
  • 結合律・交換律: 順序を入れ替えても結果は同じ。だから $(A \oplus B) \oplus B = A \oplus (B \oplus B) = A \oplus 0 = A$ となる！

教科書の「情報のデジタル化」「ネットワークとセキュリティ」に関連する解説

1. XOR演算が暗号化に使われる理由

コンピューター内のすべてのデータ（テキスト・画像・音声）は 0 と 1 のビット列 です。 XOR演算は計算速度が非常に高速であり、なおかつ「暗号化を行う関数」と「復号化を行う関数」が全く同じアルゴリズムで実現できるという非常に便利な特性を持っています。

2. 対称鍵暗号（共通鍵暗号）の仕組み

暗号化と復号化に同じ鍵（Key）を使用する暗号方式を「共通鍵暗号（対称鍵暗号）」と呼びます。 今回体験したXOR暗号はその最もシンプルな例です。現代のWi-Fi（WPA2/WPA3）やWeb通信（AES暗号）の基礎理論にも繋がっています。

3. 理論上解読不可能な「ワンタイムパッド (One-Time Pad)」

もし「平文と同じ長さの完全ランダムな鍵」を用意し、「1度だけ使って捨てる」という条件を守れば、 XOR暗号は数学的に絶対解読できない（不可解読性を持つ）暗号になります。これを「ワンタイムパッド」と呼びます。
